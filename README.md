# AcademyStorefrontController

This plugin contains the reference implementation for the Storefront controller lessons in the Shopware Academy Backend Development Essentials learning path.

## Backend Development Essentials Reference

The plugin implementation on `main` is the reference state for the Backend Development Essentials learning path.

### Plugin Features

- Uses either [The Cat API](https://thecatapi.com/) or [The Dog API](https://thedogapi.com/) to load a random image.
- Adds a link to the product detail page.
- Opens the controller response in a Storefront modal.
- Provides the API provider and optional API key as plugin configuration.

### Shopware Version and Configuration Format

The `main` branch uses `routes.php` and `services.php`, the configuration format generated by Shopware 6.7.14.0 and newer.

The tag `pre-6.7.14-xml-config` preserves the previous `routes.xml` and `services.xml` variant:

```bash
git checkout pre-6.7.14-xml-config
```

XML route and service configuration remains supported in Shopware 6.7, but it is deprecated and will no longer be loaded in Shopware 6.8.

## Frontend Development Essentials References

The Frontend Development Essentials learning path reuses this plugin for two Playwright learning units. Dedicated Git tags keep these additional states separate from the primary reference implementation on `main`.

The Playwright reference states are tested and verified with Shopware 6.7.16.0.

### LU02: Local End-to-End Testing

- `LU-02-playwright-end-to-end-test--start`: The working Storefront plugin with a minimal Playwright test project.
- `LU-02-playwright-end-to-end-test--end`: The completed local Playwright test.

The LU02 end state demonstrates how to:

- Load local Shopware connection values from `.env`.
- Configure Chromium and Firefox as Playwright projects.
- Connect Playwright to the Shopware Acceptance Test Suite fixtures.
- Create isolated product test data with `TestDataService`.
- Open the generated product page through `DefaultSalesChannel`.
- Verify that the **View Image** link is visible.
- Record screenshots and an HTML report for failed tests.

To start LU02, clone its prepared start state from your Shopware project root:

```bash
git clone --branch LU-02-playwright-end-to-end-test--start \
  https://github.com/ShopwareAcademy/AcademyStorefrontController.git \
  custom/plugins/AcademyStorefrontController
```

### LU03: Playwright Tests in CI

- `LU-03-playwright-tests-in-ci`: The completed local test with its GitHub Actions reference workflow.

LU03 explains how the same Playwright test can run in GitHub Actions. It is an explanatory learning unit, so it uses one reference tag instead of separate start and end states.

The LU03 reference demonstrates how to:

- Call Shopware's reusable E2E workflow.
- Run the Playwright test against Shopware 6.7.16.0 and `trunk`.
- Start both jobs manually or for pull requests.
- Configure a scheduled compatibility check for a project's default branch.
- Use GitHub Actions logs and Playwright artifacts to investigate failures.

The schedule trigger remains commented out in the tagged workflow because scheduled workflows only run from a repository's default branch. Projects can enable the documented trigger in their own workflow on the default branch.
